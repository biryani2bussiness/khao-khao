# Khao Khao

Khao Khao customer ordering app, merchant dashboard, and Cloudflare Worker backend.

## App entry points
- `index.html`: customer app
- `merchant.html`: merchant dashboard
- `_worker.js`: Cloudflare Pages Worker API

Cloudflare configuration, D1 database bindings, and application secrets must be configured independently. Do not commit production credentials.

Source snapshot: `KhaoKhao-Merchant-v29.zip` (21 November 2026).
